# 🛡️ Черный список токсичных игроков сервера Last Heaven

Общая база ливеров, кидал и неадекватов (Орда и Альянс).  
Система сама собирает актуальные ники в готовую команду для быстрого импорта в игру.

---

### 1. Как обновить свой черный список в игре
1. Откройте файл своей фракции: **[ОРДА (`SYNC_HORDE.txt`)](./SYNC_HORDE.txt)** или **[АЛЬЯНС (`SYNC_ALLIANCE.txt`)](./SYNC_ALLIANCE.txt)**.
2. Нажмите **Copy** (иконка копирования справа сверху от текста).
3. В WoW откройте чат (`Enter`), вставьте (`Ctrl + V`) и нажмите `Enter`.

*Готово — 50 самых свежих токсиков автоматически добавятся в ваш `/ignore`.*

---

### 2. Как добавить нового токсика в общую базу
1. Откройте таблицу **[`add_ignore.csv`](./add_ignore.csv)** и нажмите на **карандаш** (справа сверху).
2. Впишите в самом низу новую строку по шаблону (фракцию писать строго `Horde` или `Alliance`):
   ```text
   Ник,Last Heaven,Horde,Причина,ВашНик,2026-11-12,СсылкаНаСкрин
   ```
3. Нажмите зеленую кнопку **Commit changes...** и подтвердите отправку (**Create pull request**).

*После одобрения ник попадет в базу, а команды для игры обновятся сами.*
